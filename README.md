# SQL Data Warehouse & Analytics Project

## 📌 Project Overview

This project focuses on building a modern Data Warehouse using Microsoft SQL Server. It integrates data from CRM (Customer Relationship Management) and ERP (Enterprise Resource Planning) systems into a centralized environment for data management and analysis.

The goal is to transform raw business data into clean, structured, and reliable information that supports analytical queries and business insights.

---

## 🎯 Project Objectives

- Build a centralized Data Warehouse using SQL Server.
- Integrate data from CRM and ERP source systems.
- Clean and transform raw data.
- Organize data using a structured warehouse architecture.
- Develop an analytical data model for business reporting.

---

## 🏗️ Data Warehouse Architecture

The project follows the **Medallion Architecture**, consisting of three layers:

- **Bronze Layer:** Loads and stores raw CRM and ERP data.
- **Silver Layer:** Cleans, standardizes, and integrates the data.
- **Gold Layer:** Organizes business-ready data using Fact and Dimension tables for analysis.

---

## 🚀 Project Scope

### Data Engineering

- Import CRM and ERP datasets from CSV files.
- Identify and resolve data quality issues.
- Integrate data into a unified data model.
- Build the Bronze, Silver, and Gold layers.
- Design a Star Schema for analytical queries.

### Data Analytics

Use SQL to explore business data and generate insights into:

- Customer Behaviour
- Product Performance
- Sales Trends
